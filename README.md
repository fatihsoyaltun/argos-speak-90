# Argos Speak 90

Tek kullanıcılı, yerel-öncelikli, 90 günlük İngilizce çalışma uygulaması.

Hesap / Admin / cloud sync yoktur. İlerleme bu cihazın tarayıcısında saklanır.

## Kurulum

npm install
npm run dev

Production doğrulama için build + start.

Belgeler: ARCHITECTURE, USAGE, PRIVACY, PHASE_PLAN, AGENTS.
